# Generate Location Tumbnails with staticmap

Lamda to generate locations thumbnails from OSM static map API.

# Payload

`lat` : latitude, defaults to `37.7955843`

`lng` : longitude, defaults to `-122.394893`

`zoom` : zoom level, defaults to `15`

`width` : width of the image, defaults to `400`

`height` : height of the image, defaults to `220`

`prefix` : prefix for the image, defaults to `''`
